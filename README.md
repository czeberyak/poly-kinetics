   **Преамбула**
   1. Проблема: Полиуретаны застывают с разной скоростью при разной температуре. Ошибки в расчете «времени жизни» (Pot Life) ведут к порче оборудования или браку деталей.
   2. Решение: Инструмент на основе уравнения Аррениуса, который по нескольким точкам замера вычисляет энергию активации ($E_a$) конкретного эластомера и строит график кинетики отверждения для любой температуры.

# 🧪 Poly-Kinetics: Physics-Informed ML для предсказания кинетики полиуретанов

**Poly-Kinetics** — это проект на стыке химической кинетики и машинного обучения, направленный на предсказание времени жизни (pot life) и скорости отверждения полиуретановых систем.

Проект демонстрирует подход **Physics-Informed Machine Learning (PIML)**, где физические законы (уравнение Аррениуса) используются для генерации синтетических данных и создания интерпретируемых моделей, которые затем сравниваются с классическими ML-алгоритмами (Random Forest).

## ✨ Особенности

*   **Physics-Informed Data Generation**: Генератор синтетических данных, основанный на реальных физико-химических законах (уравнение Аррениуса), с учетом влияния температуры, катализатора и влажности.
*   **Сравнение моделей**: Сравнение интерпретируемой физической модели (Аррениус) и "черного ящика" (Random Forest).
*   **Интерактивный UI**: Веб-приложение на **Streamlit** для интерактивного тестирования моделей в реальном времени.
*   **Production-Ready Code**: Модульная архитектура с использованием ООП, разделением на `src/` (логика) и `app/` (интерфейс).
